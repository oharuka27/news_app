# ニュースまとめアプリ

テーマ別にニュースをピックアップして表示する Web アプリです。
**無料で運用できること** を最優先に設計しています。

## 実装方針

### 優先度と進捗

| 優先度 | 内容 | 状態 |
| --- | --- | --- |
| 1 | 無料で利用できること | ✅ 完了 |
| 2 | テーマ別タブ（世界 / 国内 / NY市場 / 東証 / 仮想通貨 / テック）、各 5〜10 件 | ✅ 完了 |
| 3 | 世界・NY市場・仮想通貨のニュースを DeepL で翻訳 | ✅ 完了 |
| 4 | 「カスタム」タブ（ユーザー入力のキーワードでニュース検索） | ✅ 完了 |

優先度ごとに 1 コミットずつ積み上げていきます。

### 無料にするための選択

- **ニュース取得元: Google News RSS**
  - API キー不要・無料・登録不要。
  - トピック別フィード（世界・テクノロジーなど）と、キーワード検索フィード
    （`https://news.google.com/rss/search?q=...`）の両方が使えるため、
    固定テーマもカスタム検索も同じ仕組みで実装できます。
  - NewsAPI などの有料/制限付き API は使いません。
  - 注意: Google News RSS は「個人の非商用利用」が前提です（フィード内の利用規約より）。
- **サーバー: Node.js + Express**
  - ブラウザから直接 RSS を取得すると CORS で弾かれるため、
    ローカルの小さなサーバーが RSS を取得して JSON で返します。
  - ホスティング費用が不要なよう、ローカルマシンでの実行を前提としています。
- **キャッシュ**（詳細は後述の「再読み込みとキャッシュ」）
  - 同じフィードは 10 分間メモリにキャッシュし、取得元への負荷とレスポンス時間を抑えます。
    カスタム検索で増え続けないよう、最大 200 フィード分（翻訳は 5,000 件）を上限に古いものから捨てます。
- **翻訳: DeepL API Free**
  - 月 50 万文字まで無料（登録時に本人確認用のクレジットカード登録が必要ですが、課金はされません）。
  - 無料枠を節約するため、翻訳するのは **見出しのみ**。
    一度翻訳した見出しはサーバーのメモリにキャッシュし、再読み込みしても再翻訳しません。
  - 目安: 1 タブ 10 件 × 約 80 文字 ≒ 800 文字。3 タブすべて新しい見出しでも 1 回 2,400 文字程度です。
  - API キー未設定でもアプリは動きます（翻訳チェックボックスが無効になるだけ）。

### テーマとニュースの取得元

各テーマ最大 10 件を表示します。定義は [src/themes.js](src/themes.js) にあり、ここを編集すればテーマの追加・変更ができます。

| タブ | フィード | 言語 | 並び順 |
| --- | --- | --- | --- |
| 世界 | Google News トピック `WORLD` | 英語 | Google の編集順 |
| 国内 | Google News トピック `NATION` | 日本語 | Google の編集順 |
| NY市場 | 検索 `"Wall Street" OR "Dow Jones" OR Nasdaq OR "S&P 500" when:1d` | 英語 | 新しい順 |
| 東証 | 検索 `東証 OR 日経平均 OR TOPIX when:1d` | 日本語 | 新しい順 |
| 仮想通貨 | 検索 `bitcoin OR ethereum OR cryptocurrency when:1d` | 英語 | 新しい順 |
| テック | Google News トピック `TECHNOLOGY` | 日本語 | Google の編集順 |

- 世界・NY市場・仮想通貨は英語圏の一次情報を拾うため英語フィードを使い、「日本語に翻訳（DeepL）」をオンにすると
  翻訳した見出しと原文を並べて表示します（オン/オフはブラウザに記憶）。
- 検索フィードは関連度順で古い記事が混ざるため、`when:1d`（直近1日）で絞り込み、新しい順に並べ替えています。
- 最後に開いていたタブはブラウザ（localStorage）に記憶し、次回もそのタブから開きます。

### カスタムタブ

- キーワードを入力して「検索」すると、Google News 検索フィード（`キーワード when:7d`）から最大 10 件を新しい順に表示します。
  ニッチなキーワードでも件数を確保できるよう、固定テーマ（直近 1 日）より広い直近 1 週間で検索します。
- 「日本語ニュース / 英語ニュース」を選べます。英語ニュースの場合は固定テーマと同様に DeepL 翻訳が使えます。
- `AND` / `OR` / `"完全一致"` / `-除外語` など Google News の検索演算子もそのまま使えます。
- 最後に検索したキーワードと言語はブラウザ（localStorage）に記憶します。

### 再読み込みとキャッシュ

キャッシュは 3 段あります。サーバー側の 2 つは **全利用者で共有** します。

| | 場所 | キー | 有効期限 | 共有範囲 |
| --- | --- | --- | --- | --- |
| ① 画面側 | `public/app.js` の `newsCache` | テーマ + 翻訳有無（カスタムは検索条件） | なし（ページ再読み込みで消える） | ブラウザごと |
| ② フィード | `src/news.js` の `cache` | フィード URL | 10 分 | 全利用者 |
| ③ 翻訳 | `src/translate.js` の `translationCache` | 英語の見出し | なし（サーバー再起動で消える） | 全利用者 |

- **タブ切り替え**: ① にあればそれを表示し、通信しません。
- **「再読み込み」ボタン**: ① を無視してサーバーに問い合わせます。② が 10 分以内なら ② の内容が返るため、
  誰がいつ再読み込みしても、前回 Google から取得した時点の同じ内容になります（Google へのアクセスは増えません）。
- **同時アクセス**: 取得中のフィード・翻訳中の見出しはサーバーが記録しており、同時に来た要求は自分で取りに行かず、
  先に走っている取得の結果を待って共有します。何人が同時に再読み込みしても Google への取得・DeepL への送信は 1 回で、全員が同じ内容を受け取ります。
- **取得失敗時**: Google がエラー（アクセス制限など）を返した場合、期限切れでも ② に前回の内容があればそれを返し、
  画面に「取得に失敗したため ○○ 時点の内容を表示しています」と表示します。この内容は ① には保存せず、次回また取得を試みます。
  前回の内容もない場合はエラーを表示します。

### 構成

```
.
├── server.js          # Express サーバー（API と静的ファイル配信）
├── src/
│   ├── news.js        # Google News RSS の取得・整形・キャッシュ
│   ├── themes.js      # 固定テーマ（タブ）の定義
│   └── translate.js   # DeepL API での翻訳とキャッシュ
├── .env.example       # 環境変数のサンプル（.env にコピーして使う）
└── public/            # フロントエンド（素の HTML / CSS / JS、ビルド不要）
    ├── index.html
    ├── app.js
    └── style.css
```

### API

| メソッド | パス | 説明 |
| --- | --- | --- |
| GET | `/api/themes` | テーマ（タブ）の一覧を返す |
| GET | `/api/news/:themeId` | 指定テーマのニュースを最大 10 件返す（例: `/api/news/tse`） |
| GET | `/api/news/:themeId?translate=1` | 翻訳対象テーマの場合、各記事に `translatedTitle` を付けて返す |
| GET | `/api/search?q=キーワード&lang=ja\|en` | カスタム検索。`lang` 省略時は `ja`。キーワードは 100 文字まで |
| GET | `/api/search?q=...&lang=en&translate=1` | 英語検索の結果に `translatedTitle` を付けて返す |

応答には次の項目が含まれます。

- `fetchedAt`: サーバーが Google から取得した時刻
- `stale`: `true` なら取得に失敗し、前回（期限切れ）の内容を返している
- `translationError`: 翻訳に失敗した場合（キー誤り・無料枠超過など）の理由。ニュースは原文のまま返す

レスポンス例:

```json
{
  "theme": "tse",
  "fetchedAt": "2026-09-29T09:30:00.000Z",
  "stale": false,
  "items": [
    {
      "title": "見出し",
      "link": "https://news.google.com/rss/articles/...",
      "source": "媒体名",
      "publishedAt": "2026-09-29T08:14:00.000Z"
    }
  ]
}
```

## ローカルでの実行方法

### 必要なもの

- Node.js 20 以上（開発時は v24 で確認）

### コマンド

```bash
# 依存パッケージのインストール（初回のみ）
npm install

# 起動
npm start

# 開発用（ファイル変更で自動再起動）
npm run dev
```

起動後、ブラウザで http://localhost:3000 を開きます。

### DeepL 翻訳を使う場合（任意）

1. https://www.deepl.com/ja/pro-api から **DeepL API Free** に登録し、認証キー（末尾が `:fx`）を取得
2. `.env` を作成してキーを設定

   ```bash
   cp .env.example .env
   # .env を開いて DEEPL_API_KEY=xxxxxxxx:fx を記入
   ```

3. `npm start` で起動し、ログに `DeepL 翻訳: 有効` と出れば OK

`.env` は `.gitignore` 済みなので、キーがコミットされることはありません。
使用済み文字数は DeepL のアカウントページで確認できます。

ポートを変える場合:

```bash
PORT=8080 npm start
```

## 補足・トラブルシューティング

- **翻訳だけ失敗する（ログに `ETIMEDOUT`）**:
  Node.js は IPv4/IPv6 の接続先を 250ms ごとに切り替えるため、接続に時間がかかるサーバーだと失敗することがあります
  （WSL 環境で DeepL への接続時に発生を確認）。`server.js` で待ち時間を 2 秒に延ばして対処済みです。
